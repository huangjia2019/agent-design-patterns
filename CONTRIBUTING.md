# Contributing to ADPS

- Documents: [English guide](docs/CONTRIBUTING.md) · [中文协作规范](docs/CONTRIBUTING.zh-CN.md).
- Code: propose a scoped change with tests. Keep existing pattern interfaces compatible, and open an issue before changing the catalogue or introducing a new pattern.
- Website paragraph suggestions: use [ADPS discussions](https://adpsagent.com/contribute/).

The accepted document source is in this repository. Website publication is a separate reviewed action, with an exact source commit recorded on each article. A contributor can submit a PR without being a repository member.
